# 互動播放器（本機開啟）

在此資料夾開啟終端機執行：

    python -m http.server 8000

再以瀏覽器開啟 http://localhost:8000/player/index.html

功能：播放／暫停（空白鍵）、重播、進度拖曳、章節跳轉、字幕開關，以及「文法錯誤或風格改善？」互動題（30 題取自 reviews.json 的實際修改對照，判定以評閱標籤為準）。
只有中文配音版（中英字幕），依使用者指定。畫面依操作日誌重建，不是原始桌面錄影。
字型：Noto Sans TC（SIL Open Font License 1.1）。學生姓名與學號已在影片用圖片副本中遮罩。
